# Юридическая платформа — UI/UX прототип

Прототип B2B-платформы, в которой AI-агент выполняет работу юриста:
ведёт дело, работает с документами и сроками, предлагает действия —
юрист подтверждает, изменяет или отклоняет.

## Стек

- **Vite** + **React 18** + **TypeScript**
- **MUI (Material UI) v5** — UI-компоненты
- **MobX** — реактивное состояние экрана
- **RxJS** — потоки данных (стриминг ответа агента, очередь карточек)
- **Архитектура MVVM**: Service (RxJS) → ViewModel (MobX) → View (React)

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 в браузере.

## Сценарий для проверки

1. **Сегодня** — при входе агент показывает дайджест с карточками P0–P1
2. Справа — очередь карточек, отсортированных по приоритету
3. Нажмите на карточку P0 (красная) → раскроются детали → нажмите «Подтвердить»
4. Карточка исчезнет из очереди, агент ответит в чат
5. Перейдите в **Договоры** или **Судебные дела** через левую навигацию
6. Выберите чат-задачу слева → откроется диалог
7. Нажмите на ссылку-источник в сообщении → откроется DocumentDrawer
8. Закройте Drawer и вернитесь к работе

## Пространства

| Пространство | Вкладки | Типы карточек |
|-------------|---------|--------------|
| Договоры | Договоры · События · Документы | approval, payment, notification, review |
| Судебные дела | Дела · События · Документы | deadline, payment, notification, review |

## Типы карточек

| Тип | Действия |
|-----|---------|
| approval — Согласование документа | Подтвердить / Изменить / Отклонить |
| deadline — Контроль срока | Создать задачу / Изменить дату / Отклонить |
| payment — Платёж / расход | К оплате / Изменить / Отклонить |
| notification — Уведомление | Отправлено / Изменить / Отклонить |
| review — Запрос проверки | Принять к сведению / Создать задачу / Отклонить |

## Приоритеты

| Приоритет | Цвет | Описание |
|-----------|------|----------|
| P0 | 🔴 Красный | Срок сегодня/просрочен |
| P1 | 🟠 Оранжевый | Срок 1–3 дня |
| P2 | 🔵 Синий | Плановое действие |
| P3 | ⚪ Серый | Информация |
