# ПравоТех — UI/UX прототип юридической платформы с AI-агентом

[Демо на GitHub Pages](https://artyomusov.github.io/PravoTech/)

B2B-платформа, в которой AI-агент выполняет работу юриста: ведёт дело, работает с документами и сроками, предлагает действия — юрист подтверждает, изменяет или отклоняет.

## Стек

- **Vite** + **React 18** + **TypeScript**
- **MUI (Material UI) v5** — UI-компоненты, кастомная тема
- **MobX** — реактивное состояние (observable, action, computed)
- **RxJS** — потоки данных (стриминг ответа агента, очередь карточек)
- **Архитектура MVVM**: Service (RxJS) → ViewModel (MobX) → View (React)
- **DI**: ручной контейнер без декораторов

## Быстрый старт


## Архитектура

### MVVM + MobX + RxJS

- **RxJS** — только в сервисах (Data Layer): стриминг ответа агента, статусы долгих операций
- **MobX** — только в ViewModel/Store: синхронное реактивное состояние экрана
- **Мост**: ViewModel подписывается на RxJS-потоки, обновляет mobX-observable через `runInAction`
- **View** — `observer`-компоненты, подписанные на MobX-сторы

### Компонент-стратегия для карточек

`cardComponents: Record<CardType, ComponentType<CardProps>>` — маппинг типов карточек к React-компонентам. Добавление нового типа = новый компонент + запись в маппинг, без if/else.

### Единый RootStore

`RootStore` через React Context — композиция всех ViewModel. Точечная подписка: observer оборачивает компонент, а не весь RootStore.

## Навигация

- **Сегодня** — дайджест от агента, очередь карточек P0–P3, чат, календарь
- **Мои дела** — единое рабочее пространство с вкладками:
  - **Чат** — диалог с агентом по выбранной задаче
  - **Суд. дела** — документы судебного пространства
  - **События** — история действий (AuditPanel)
  - **Документы** — все документы
- **Настройки** — раздел в разработке

## Пространства (конфигурации)

| Пространство               | Вкладки                               | Типы карточек | Навыки агента |
| -------------------------- | ------------------------------------- | ------------- | ------------- |
| Мои дела (комбинированное) | Чат · Суд. дела · События · Документы | все типы      | все навыки    |

Каждое пространство настраивается через `WorkspaceConfig`:

- `cardTypes` — какие типы карточек отображать
- `agentSkills` — навыки агента (для кастомизации ответов)
- `tabs` — вкладки с типами контента (`chat-list`, `document-list`, `event-list`)

## Сценарий для проверки

1. **Сегодня** — при входе агент показывает дайджест с карточками P0–P1
2. Справа — очередь карточек, отсортированных по приоритету
3. Нажмите на карточку P0 (красная) → раскроются детали → нажмите «Подтвердить»
4. Карточка исчезнет из очереди, появится запись в истории действий
5. Перейдите в **Мои дела** через левую навигацию
6. Выберите чат-задачу слева → откроется диалог с агентом
7. Перейдите по вкладке **События** → увидите историю действий по выбранной задаче
8. Нажмите на ссылку-источник в сообщении → откроется DocumentDrawer
9. Закройте Drawer и вернитесь к работе

## Типы карточек

| Тип                               | Действия                                        |
| --------------------------------- | ----------------------------------------------- |
| approval — Согласование документа | Подтвердить / Изменить / Отклонить              |
| deadline — Контроль срока         | Создать задачу / Изменить дату / Отклонить      |
| payment — Платёж / расход         | К оплате / Изменить / Отклонить                 |
| notification — Уведомление        | Отправлено / Изменить / Отклонить               |
| review — Запрос проверки          | Принять к сведению / Создать задачу / Отклонить |
